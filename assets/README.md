# Asset provenance

This directory contains only reusable, stable brand and ecosystem artwork. It is
not a mirror of every image used by each product.

## Release 1.3.0 additions

- `chains/robinhood.svg` and `chains/arc.svg` were copied from
  `9mm-exchange/landing`, GitHub `launch` at `48b4da68a802e105b30c2f45587e24fac9e77064`,
  after fetching on 2026-07-28. They support accurate informational presentation
  only; both chains remain `SOON` in this reference.
- `chains/chia.webp` was copied from `9mm-exchange/xch-terminal`, GitHub `beta` at
  `602ffc07209000e8369eb715e442d9ca1cd306f7`, after fetching on 2026-07-28. It is
  the green Chia leaf used by the current XCH terminal branch. The pre-existing
  `chains/chia.png` is retained for compatibility with prior references.

## Audit notes

- The hub's masterbrand marks, favicons, social card, token/NFT art, and 9x
  protocol artwork already match files in this repository.
- Claim's masterbrand logo, favicon set, and Genesis OG cover already match files
  in this repository. Its blue `background.png` is product-specific artwork, not a
  cross-surface brand asset.
- Royal Gate uses the existing masterbrand logo, favicon set, and social card; it
  has no separate reusable source artwork to add.
- XCH's third-party venue and token logos are product/runtime assets. They are not
  promoted to canonical 9MM branding here.
- The landing branch includes historical product screenshots with older visual
  systems. They are intentionally not used as current branding references.
